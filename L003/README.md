# Day 003 — Information

## Core Idea

Information is the ability to distinguish between different states (possibilities).

--

A light switch has two possible states.

```
OFF
ON
```

One state means one thing.
The other state means something else.

The difference between those possibilities **is information**.

Computers don't store ideas.

They store distinguishable states.

Programming is the process of creating, manipulating, and interpreting those states.

---

## Examples

- `eg1_switch.py` demonstrates information using a simple light switch.
- `eg2_trafficlight.py` shows that information is **not limited to two states**.
- `information.py` demonstrates the same idea using a Python class.

Notice that **information exists independently of programming constructs** like variables, objects, or classes.

Those are simply different ways of representing and manipulating information.
