# Day 005 — Binary

## Core Idea

Binary is one way of representing information.

Computers use only two physical states.

```
0
1
```

Those states can represent numbers.

Numbers can represent letters.

Letters can represent words.

Words can represent ideas.

The binary changes.

The information does not.

---

## Examples

- `eg1_decimal_binary.py` represents a number in binary.
- `eg2_letters.py` shows how a letter becomes a number, then binary.
- `binary.py` demonstrates the same idea with an entire word.

## Think

If computers only store **0s** and **1s**,

how can they represent:

- music?
- images?
- videos?
- entire books?

---

## Key Takeaway

**Binary is a representation, not the information itself.**
