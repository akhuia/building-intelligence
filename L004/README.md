# Day 004 — Representation

## Core Idea

Information is abstract.

Representation is how we choose to express it.

The number

```
42
```

can be represented in many ways.

```
42
101010
0x2A
XLII
forty-two
```

The representation changes.

The underlying information does not.

---

## Examples

- `eg1_number.py` represents a number.
- `eg2_text.py` represents text.
- `representation.py` shows that the same information can have multiple representations.

---

## Think

If the same information can have many representations,

which representation does the computer actually store?

---

## Key Takeaway

**Representation is not information.**
